# Зависимости и происхождение инструментария

Состав повторно проверен 29.10.2026. В Cargo.toml нет внешних зависимостей; Cargo.lock
содержит только пакет `nml01-core` версии 0.3.0-internal.1. Rust использует стандартную
библиотеку. Python-адаптер, хранилище и проверяющий используют стандартную
библиотеку Python и соседний собственный модуль `storage`.
Инвентаризация импортов — `evidence/dependencies.json`.

| Компонент | Как используется | Что входит в кандидат |
|---|---|---|
| Rust / Cargo 1.98.0 | Уже установленный инструмент сборки | Исходник проекта и метаданные Cargo; без компилятора и стандартной библиотеки |
| Python 3.9+ | Уже установленный интерпретатор с `sqlite3`, `fcntl` и другими стандартными модулями | Только собственные скрипты; без интерпретатора и его библиотек |
| SQLite | Через стандартный модуль Python `sqlite3` | Вызовы API (программного интерфейса); без копии SQLite |

По [официальной странице Rust](https://rust-lang.org/policies/licenses/)
проекты Rust обычно используют Apache-2.0 / MIT; конкретный состав требует
проверки в соответствующем репозитории. Это не лицензия нашей программы.

[Документация Python 3.9](https://docs.python.org/3.9/license.html) указывает PSF
License Agreement (лицензионное соглашение) и отдельно перечисляет включённые компоненты с другими
условиями. Исходники стандартной библиотеки и примеры из документации Python
в этот кандидат не копируются.

[SQLite](https://www.sqlite.org/copyright.html) описывает поставляемые код и
документацию как общественное достояние и отдельно оговаривает некоторые
сценарии сборки. В данном кандидате SQLite не распространяется.
