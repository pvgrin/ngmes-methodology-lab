# Состояние сборки 0.2.0-rc1

Дата подготовки: 25.10.2026. Пакет исходников подготовлен для разрешённой
владельцем публичной публикации NGMES Methodology Lab 0.2.0-rc1.
Код продукта имеет версию 0.2.0; rc1 означает первый кандидат выпуска.

Утверждённое назначение: [pvgrin/ngmes-methodology-lab](https://github.com/pvgrin/ngmes-methodology-lab).
Код, документация и синтетические примеры — [Apache-2.0](LICENSE).
Copyright 2026 Pavel Grinevich; область применения указана в [NOTICE](NOTICE).

Этот файл фиксирует состояние на момент упаковки. Создание репозитория,
отправка Git и проверка публичной доступности выполняются отдельным шагом;
само наличие этого файла не свидетельствует об уже состоявшейся публикации.
Факт опубликования и соответствие состава проверяются в целевом репозитории.

Предметное поведение сохранено: семь сценариев / 14 контрольных срезов.
Cargo.toml получил только метаданные лицензии, автора и адреса репозитория.
Исходник Rust, Python-адаптер, хранилище, Cargo.lock и восемь входных файлов
совпадают с принятым результатом. Текущие хеши и две чистые сборки описаны
в `evidence/public-verification.json`; старый бинарный хеш не используется
как обещание для нового состава. Бинарники и среда исполнения не поставляются.

Воспроизведение: [README.md](README.md). Состав связан `MANIFEST.json`;
публичные свидетельства очищены от личных путей и внутренней координации.
